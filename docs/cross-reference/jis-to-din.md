!!! note "Key Differences"
    JIS batteries are generally **longer and taller** than DIN equivalents. DIN batteries are **wider** (175 mm standard width) with a more compact layout. Hold-down systems differ: JIS uses B00 (top frame), DIN uses B13 (bottom rail).
