# DIN Battery Standard

**DIN** (Deutsches Institut fur Normung) is the standard automotive battery specification used across Europe and widely adopted in Africa and the Middle East.

## How DIN Battery Codes Work

DIN battery model numbers are 5 or 9 digits that encode dimensions and performance:

```
Example: 60038

600 = Series identifier (case size)
38  = Capacity code (higher = more Ah)
```

DIN batteries are also commonly referred to by short codes like **DIN66**, **DIN100**.

### DIN Terminal System

DIN batteries use **standard post** terminals — similar to T1 small post:

| Terminal | Post Diameter |
|----------|:---:|
| Positive (+) | ~19.5 mm |
| Negative (-) | ~17.9 mm |

### DIN Hold-Down System

DIN batteries typically use **B13** (bottom rail) hold-down — the battery is secured by a lip at the base.

### DIN Polarity Convention

DIN standard polarity is **[0]** (right-positive):
- Left terminal: Negative (-)
- Right terminal: Positive (+)

When viewed from the terminal side.
