# BCI Battery Standard

**BCI** (Battery Council International) is the standard automotive battery specification used in North America.

## BCI Group Sizes

BCI batteries are identified by **Group Numbers** that define the physical case dimensions and terminal layout:

| Group | Typical Application | Dimensions (LxWxH mm) |
|-------|---------------------|----------------------|
| Group 24 | Mid-size vehicles | 260 x 173 x 225 |
| Group 27 | Larger vehicles | 306 x 173 x 225 |
| Group 31 | Commercial/Heavy duty | 330 x 173 x 240 |
| Group 34 | Performance vehicles | 260 x 173 x 200 |
| Group 35 | Honda/Toyota | 230 x 175 x 225 |
| Group 48 (H6) | European vehicles | 278 x 175 x 190 |
| Group 49 (H8) | Luxury vehicles | 353 x 175 x 190 |
| Group 94R (H7) | European vehicles | 315 x 175 x 190 |
