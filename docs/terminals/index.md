# Battery Terminal Types

## JIS Terminals (T1)

JIS standard batteries use **T1** terminals with two size variants:

| Variant | Positive (+) | Negative (-) | Used On |
|---------|:---:|:---:|---------|
| **T1 Small** | O14.7 mm | O13.0 mm | Standard SLI batteries |
| **T1 Large** | O19.5 mm | O17.9 mm | Heavy-duty batteries |

### Polarity Convention [0]

Standard JIS polarity is **[0]** (right-positive):

```
Viewed from terminal side (terminals closest to you):

     (-)          (+)
     Left        Right
```

## DIN Terminals

DIN standard batteries use similar post-type terminals:

| Terminal | Post Diameter |
|----------|:---:|
| Positive (+) | O19.5 mm |
| Negative (-) | O17.9 mm |

Polarity: [0] — Left Negative, Right Positive (same as JIS).

## Hold-Down Systems

| System | Standard | Description |
|--------|----------|-------------|
| **B00** | JIS | Top frame clamp across battery |
| **B13** | DIN | Bottom rail — lip at base of battery |
